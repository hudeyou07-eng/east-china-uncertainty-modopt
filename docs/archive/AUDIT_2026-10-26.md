## 二、必须处理：影响结论正确性

### P0-1　C1 按 Plan 自己的标准不成立

Plan §4 的成功标准是「点误差不劣于强基线 **且** 80%/95% 覆盖率接近名义覆盖」。
实测（`calibration_summary.csv`）：

| 缺失几何 | 方法 | scaled_mae | coverage95 |
|---|---|---|---|
| consecutive_years | hierarchical_rw | 0.1675 | 0.955 |
| | interpolation | **0.1406** | 0.865 |
| | mice | **0.1266** | 0.840 |
| single_cell | hierarchical_rw | 0.1746 | 0.950 |
| | interpolation | **0.1667** | 0.887 |
| | mice | **0.1555** | 0.865 |
| province_group | hierarchical_rw | **0.1776** | 0.975 |
| | interpolation | 0.1893 | 0.825 |
| | mice | 1.1821（崩溃） | 0.733 |

覆盖率校准主方法最好（0.950–0.975 对名义 0.95），但点误差在 2/3 几何上劣于基线
（年段劣 19%/32%，单点劣 4.7%/12.3%）。**不能声称全面占优。**

可行表述：主方法以点精度换取覆盖率校准；MICE 在 province_group 下崩溃，说明它
不是稳健基线。

**处理结果（16:31）**：已按此改写 C1 的最小可信证据，记为 Plan 修订 `R-2026-10-26-a`，
保留原文并附实测依据。未做收缩重跑。

### P0-2　CDG 情景在主口径下禽肉没有指南约束

主口径 K=3 = G02/G05/G08，含 G05 禽肉但不含 G06 红肉。
CDG 的「畜禽肉 40–75」是 `G05+G06` 联合约束，成员不全时按设计必须整条跳过。
结果（`decision_bounds.csv`，上海）：

- G02 蛋 40–50（指南）
- G05 禽肉 **0–71.8（技术边界 = 2×基线，不是指南）**
- G08 蔬菜 300–500（指南）

即 CDG 情景下三分之一的组失去指南约束，禽肉可自由到 71.8 g/天。
**CDG 情景的禽肉结果不可解读为「符合指南」。**

**处理结果（16:31）**：追查后发现根因不是「缺一条禽肉约束」，而是 **CDG 约束不可满足**。

| 省 | 红肉 G06 | 禽肉 G05 | 畜禽肉合计 | 超 CDG 上限 75 |
|---|---|---|---|---|
| 上海 | 86.5 | 35.9 | 122.4 | 是 |
| 安徽 | 82.9 | 39.5 | 122.5 | 是 |
| 山东 | 70.6 | 21.2 | 91.8 | 是 |
| 江苏 | 87.0 | 36.0 | 123.1 | 是 |
| 江西 | 94.4 | 32.4 | 126.8 | 是 |
| 浙江 | 90.9 | 34.2 | 125.0 | 是 |
| 福建 | 93.5 | 37.1 | 130.6 | 是 |

若红肉固定在实际基线（不进模型），禽肉须满足的剩余区间为负（上海 [-46.5, -11.5]）。
7 省畜禽肉合计全部超过 75，说明 CDG 情景**必然要求红肉下降**，红肉必须是决策变量。

已改：主口径 `trace_as_valid=True`，K=3 → **K=4**（G02/G05/G06/G08），
记为 Plan 修订 `R-2026-10-26-b`；原 K=3 保留为 `group_audit_k3_strict.csv` 作偏离对照。
联合约束 `G05+G06 ∈ [40,75]` 现可在主口径生效。

**新增代价（需在 B2 处理）**：G06 价格面板不完整——51 个省-年观测中仅 27 行三品类齐全，
23 行只有单品类，等权退化为单品类价。G3 断言「主口径等于最低价比例 <50%」实测 **45%**，
已接近阈值。B2 必须同时报告 `price_complete_equal`（仅齐全行严格等权）口径的结果。

## 三、口径不一致：影响解读

### P1-1　`price_observations` 与 `group_prices` 的观测数不同口径

- `group_audit.csv` G06：**106**（品类 × 省 × 年）
- `group_prices.csv` G06：**51**（省 × 年聚合后）

门槛 18 未声明针对哪个口径。前者容易达标，后者较严。

### P1-2　`environment_coverage` 映射语义偏移

Plan §3 要求该列是覆盖率数值，实际 `group_audit.csv` 给的是 `environment_gate`（布尔）。
`model_manifest.json` 的 `plan_column_mapping` 已注明"细分见 count 列"，但列名不对应，
外部复核者按 Plan 读表会拿到布尔值。

### P1-3　G11 的排除原因表述错误

审计表写「硬营养系数不全(0/11项达标，0种食物)」，
真实原因是 `src/ontology.py` 中 G11 的 `nutrition_groups` 为空——**根本没做映射**。
「未映射」与「数据缺失」性质不同，前者是本体设计缺口。
