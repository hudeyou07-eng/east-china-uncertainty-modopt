# Reviewed smoke evidence

These small files are exported from the repository-level verification run `repo_local_data_smoke_20261015_193847` after the cleaned input data and repository-local paths were added.

They demonstrate that the audit, structured masking, four imputation methods, metric export, and synthetic chance-constrained MILP execute successfully using data committed under `data/input/`. The calibration profile used only 2 folds × 2 repeats, and the optimization result is marked `synthetic_fixture_only`. These files are engineering evidence, not paper results.
